# Nghiệm thu P1

Chỉ dùng dữ liệu `real`. Chưa đo thì ghi "chưa đo", không bịa số.

| # | Hạng mục | Ngưỡng | Kết quả đo | Đạt? | Ngày |
|---|---|---|---|---|---|
| #1 | Sai số mực sông, >= 8 mốc x 3 lần | MAE <= 10 mm (mục tiêu 5), max <= 15 | chưa đo | | |
| #2 | Sai số mực hồ, >= 6 mốc x 3 lần | MAE <= 10 mm | chưa đo | | |
| #3 | Độ lặp, 100 mẫu nước đứng yên | Độ lệch chuẩn <= 3 mm | chưa đo | | |
